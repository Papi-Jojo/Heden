# Îlot

Carte interactive pour noter les coins de Paris et de la petite couronne visités lors d'une recherche d'appartement.

- **Carte** : poser une zone circulaire, l'étirer, la noter selon ses critères. La zone prend une couleur du rouge (0) au vert (100).
- **Profil** : profils types ou critères personnalisés et pondérés.

Site statique en un seul fichier (`index.html`, Leaflet, fonds OpenFreeMap (sans clé) et Esri, géocodage Nominatim). Les données restent dans le navigateur ; export et import JSON depuis l'onglet Profil.
